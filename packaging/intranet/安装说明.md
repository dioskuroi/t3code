# t3code 内网版安装说明

适用：macOS（Apple 芯片）。本文件随构建产出，放在 dmg 与资源包旁边；文中的 `<版本>` 见文件名。

## 包内文件

| 文件                                             | 说明                                 |
| ------------------------------------------------ | ------------------------------------ |
| `T3-Code-<版本>-intranet-arm64.dmg`              | t3code 桌面应用（内网版）            |
| `t3code-intranet-bundle-<版本>-mac-arm64.tar.gz` | 预览浏览器、omp 配置包、`install.sh` |
| `SHA256SUMS`                                     | 上面两个文件的校验和                 |

## 准备

- 内网模型网关的地址、key 和模型 id。网关需要兼容 OpenAI Chat Completions（`POST {地址}/chat/completions`，流式）。
- omp 已安装，终端里 `which omp` 能找到它的路径。

## 安装

1. **校验**：在本目录执行 `shasum -a 256 -c SHA256SUMS`，两行都应是 `OK`。

2. **安装 t3code**：打开 dmg，把 `T3 Code (Nightly).app` 拖到有写入权限的位置。「应用程序」或桌面都可以，t3code 不要求装在「应用程序」里。

   放好后不要再移动或改名。移动了也没关系，打开一次 t3code，它会自己把命令行工具 `t3` 指到新位置。

   这个包没有苹果认可的开发商签名。文件若带着隔离属性，首次打开会被拦截（「无法验证」或「已损坏」）。经浏览器下载，或从带该属性的压缩包、镜像里解压出来的文件通常会带；经普通文件拷贝、U 盘或内网共享复制的一般不带。被拦截时，在终端去掉该属性后再打开。把路径换成实际位置，把应用图标拖进终端窗口即可得到路径：

   ```sh
   xattr -cr ~/Desktop/"T3 Code (Nightly).app"
   ```

   「系统设置 → 隐私与安全性 → 仍要打开」也能打开，但隔离属性还在。带这个属性的应用启动时，可能被系统挪到一个临时的随机路径去运行。t3code 会把自己的位置记成那个临时路径，命令行 `t3` 在 t3code 退出后就不能用了，要再打开一次 t3code 才恢复。只用界面、不用终端里的 `t3` 的话不受影响。

3. **预览浏览器**：解压资源包，进入解压后的目录执行 `sh install.sh`。它只把 t3code 预览功能需要的浏览器放到 `~/.t3/tools/` 下，不改其他文件；重复执行无副作用。

4. **配置 omp**：按资源包里 `omp-acp/README.md` 操作——改 `models.yml` 的三处、写 key、运行 `apply-omp-settings.sh`、用 `omp models intranet` 自查。

5. **t3code 接入 omp**：打开 t3code → Settings → Providers → Add provider → Show more → **Local ACP command**。可执行文件填 `which omp` 的输出（绝对路径），参数填 `acp`，名称随意。

6. **中文界面**：Settings → Display → Language，选中文。

## 首次启动确认

- 启动后直接进入主界面，没有登录入口。
- 新建会话，在模型选择器里选内网模型，发一句话能收到回复。
- 命令行工具 `t3` 记的位置是对的，装在桌面时尤其要确认。打开过一次 t3code 后，在终端执行 `grep '^app=' ~/.t3/bin/t3`，显示的应该是你放置 t3code 的真实路径，而不是 `/private/var/folders/…/AppTranslocation/…` 下面的临时路径。是临时路径的话，按上面第 2 步执行 `xattr -cr`，再打开一次 t3code。
- 关于界面显示的版本号与 dmg 文件名里的一致。

## 已知限制

- **会话标题、commit message、分支名不会自动生成**，需要手写。t3code 的文本生成不支持 omp 这类 ACP 实例。
- **内网不可用的功能**：T3 Connect / 远程接入、GitHub 集成、自动更新、问题诊断（triage）、语音输入、`t3 update` 与 `t3 service install`。
- omp 启动时会在后台尝试访问 `catalog.stencil.so`（共享模型目录），偶发还会尝试它内置云端 provider 的模型列表地址（已见到 `coding-intl.dashscope.aliyuncs.com`、`hyper.charm.land`）。这些都关不掉，失败后回退到内置目录，不影响使用，由防火墙拦截即可。
- **升级**：没有自动更新。需要升级时在外网机器上重新构建，再把 dmg 和资源包一起拷进来成对覆盖安装。
